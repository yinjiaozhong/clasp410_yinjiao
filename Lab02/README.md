
# ODE Lab 2

This code solves competition, predator-prey, and Lorenz
ODE systems using Euler's method and RK45.

## Requirements

- Python 3
- NumPy
- SciPy
- Matplotlib

## How to Run

1. Download the Python file from this repository.
2. Install the required packages:

   pip install numpy scipy matplotlib

3. Run the script:

   python ode_lab.py

## Outputs

The script automatically creates a folder named
`figures` in the same directory as the Python file.

All 13 figures are generated and saved as PNG files
at 300 dpi.

The numerical results are printed in the terminal.

No external datasets or manually configured file
paths are required.
